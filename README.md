# Portfolio Management App 📈

Dự án xây dựng hệ thống quản lý danh mục và phân tích đầu tư định lượng chuẩn Bloomberg Terminal theo tiến trình 9 bước từ bài báo.

## 🌿 Nhánh hiện tại: `step-1-myapp0`
- **Tệp chính:** `myapp0.py`
- **Mô tả:** Ứng dụng "Hello World" cơ sở kiểm tra cài đặt môi trường Streamlit.

## 🚀 Hướng dẫn chạy
```bash
streamlit run myapp0.py
```
